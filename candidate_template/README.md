# Candidate Template

This folder replaces the personal reference material that was previously stored in the repository.

Use these files as the starting point for your own candidate data:

- `candidate_profile.template.json`: structured background, education, skills, and experience
- `github_profile.template.json`: GitHub highlights and project signals
- `portfolio.template.json`: featured work, links, and outcomes

Recommended flow:

1. Copy each `*.template.json` file.
2. Rename the copies to remove `.template`.
3. Fill them with your own real data.
4. Place the completed files where your run pipeline expects them, or adapt the pipeline to ingest them directly.

Do not commit private resumes, API keys, or personally sensitive documents unless you intentionally want them published.
